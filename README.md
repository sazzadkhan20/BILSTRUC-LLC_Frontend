# BILSTRUC LLC Website

Static property-maintenance website for **BILSTRUC LLC** (HTML + CSS + light JS, no framework).

## Pages

- `index.html` — landing page (hero, services, about, FAQs, contact, map, footer)
- `privacy-policy.html` — privacy policy

## Deploy

Upload the project root to any static host (Apache, Nginx, Netlify, cPanel, S3, etc.).

Required files/folders:

```
index.html
privacy-policy.html
css/
js/
assets/
```

Open `index.html` in a browser locally, or point the server document root to this folder.
